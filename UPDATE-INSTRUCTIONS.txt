更新说明

1. 解压此更新包。打开 GitHub 博客仓库，点 Add file → Upload files。
2. 将 update 文件夹里面的所有文件和文件夹拖入上传区，不要把 update 外层目录一起上传。
3. 点击 Commit changes，直接提交到 main。已有同路径文件会被更新。
4. 等待 Actions 中最新的 Pages 部署成功，然后刷新网站；如果仍显示旧样式，按 Ctrl+F5。

本更新包不包含 _posts、about.md、_config.yml，不会覆盖你的文章和个人介绍。
背景图：assets/images/hero.jpg；头像：assets/images/avatar.jpg。
昵称 yyqy 位于 index.html。打字句子位于 _layouts/default.html 的 typed-text 元素中。
搜索索引由 GitHub Pages 自动生成，可搜索标题、分类、正文。
封面原图为正方形，横屏会自动裁掉上下部分；手机使用同一图片自动适配。
如你自行修改过 index.html、_layouts/default.html 或 assets/style.css，请先备份，它们会被本更新替换。
